À propos du projet

Ce site web est un faux réseau social conçu pour s'inscrire dans l'univers d'un jeu vidéo fictif. Il sert d'ARG (Alternate Reality Game) / source externe interactive : les joueurs doivent y explorer les publications, messages et profils des victimes du jeu pour dénicher des indices et progresser dans l'aventure.

Fonctionnalités clés

Immersif : Fausse interface de réseau social alimentée par les histoires des victimes.

Gameplay externe : Éléments d'enquête à résoudre en dehors du jeu principal pour débloquer la suite de l'intrigue.
